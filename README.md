# Breaking Kubernetes

A workshop on breaking (and understanding) Kubernetes.

## Guide to the repo

| Path | Contents |
|------|----------|
| `manifests/` | Lab environment: namespaces, ServiceAccounts, Roles/RoleBindings, ClusterRoles/ClusterRoleBindings, and flag Secrets. Apply with `kubectl apply -k manifests/`. |
| `scripts/gen-serviceaccount-kubeconfig.sh` | Generates a low-privilege kubeconfig (into `kubeconfigs/`) for the starting ServiceAccount. |
| `docs/00-setup.md` | Verify the kind cluster, apply manifests, generate the kubeconfig. |
| `docs/01-enumeration.md` | Technique 1: enumerate permissions with built-in `kubectl` tools. |
| `docs/02-pod-pivot.md` | Technique 2: create a pod using another namespace's ServiceAccount. |
| `docs/03-cluster-admin-bind.md` | Technique 3: bind to `cluster-admin`. |
| `docs/CHEATSHEET.md` | Handy `kubectl` commands for the workshop. |
| `docs/gifs/` | Recorded demos for each step. |

### Getting started

1. Have a local [kind](https://kind.sigs.k8s.io/) cluster running (Docker or Podman) and `kubectl` installed.
2. Follow the docs in order, starting with [docs/00-setup.md](docs/00-setup.md).

### Related

To bootstrap a cluster for this workshop, see [sswanso/k8s-bootstrap](https://github.com/sswanso/k8s-bootstrap).
